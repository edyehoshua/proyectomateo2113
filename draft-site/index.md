# Volver al texto

No te pedimos que nos creas. Esta página reúne información, fuentes y preguntas para examinar enseñanzas recibidas sobre Yehoshúa HaMashíaj, la profecía, la Torah, el evangelio y la vida bajo el Ruaj.

El propósito no es atacar personas. Es poner las enseñanzas delante del texto para que cada lector pueda discernir.

## Cómo leer esta página

Cada afirmación debe mostrar su fuente, el texto bíblico, el contexto y un veredicto claro. Las dudas pendientes se marcarán como pendientes; no se presentarán como certezas.
